Registrar personal autorizado

Solo el operador concede roles. Cada registro representa una persona o equipo con capacidad para una tarea.

Telegram: usa tg: seguido del ID de la persona como identificador estable y el mismo ID numérico como contacto privado. Voz: móvil autorizado con prefijo internacional. El contacto se borra del formulario y no se guarda en el navegador. Web no necesita contacto.
