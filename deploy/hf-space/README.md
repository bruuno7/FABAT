# MANDO — live demo

Control room of MANDO: a swarm of HappyRobot agents coordinating a 40,000-person festival crisis.
The venue, crowd, resources and time are **simulated**; the agents, their tools and the decisions are real.
Open the Space, press **space** to start the clock, **K** to jump to the key moment. Source and docs: see the team repository.
